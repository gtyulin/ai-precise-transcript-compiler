# AI 精準逐字稿編譯器（AI Precise Transcript Compiler）

把長篇逐字稿（訪談、課堂、會議、演講）**編譯**成可追溯的講義或研究筆記，而不是讓 AI 一次讀完就自由摘要。

## 它解決什麼問題？
一般叫 AI「整理逐字稿」，常見問題是：長稿後段被跳過、補進講者沒說的因果、把有新細節的話當重複刪掉、重點找不回原文在哪。

這個 skill 借用**質性研究編碼**的做法來防止這些問題：

| 質性研究的做法 | 這個 skill 的步驟 |
|---|---|
| 逐段閱讀、標行號 | 預切割＋來源索引 |
| 意義單位、開放編碼 | 逐批切意義單位，只改語序不加內容 |
| 研究者自我檢核 | 每批完整性閘門 |
| 持續比較、主軸編碼 | 概念合併但保留反例與來源 |
| 類別 → 主題 | 意義單位 → 概念 → 類別 → 主題 → 講義段落 |
| 稽核軌跡 | 雙向來源稽核（講義→原文、原文→講義） |

每一句結論都能回到原文位置，每一段原文都有「已納入／合併／排除／待確認」的去向。

## 安裝
把 `ai-precise-transcript-compiler/` 資料夾放進你的 AI agent 的 skills 資料夾：
- Claude Code：`~/.claude/skills/`
- Codex：`~/.codex/skills/`
- 其他支援 SKILL.md 的工具：依各家說明放置；網頁版 AI 也可以把 `SKILL.md` 內容貼進專案指示。

## 使用
對 agent 說：「請用精準逐字稿編譯流程，把這份逐字稿整理成講義」，並附上逐字稿檔案（txt、md、docx、pdf、srt、vtt）。

## 注意
- 含可辨識個案、學生、家長或敏感會議資料時，請在本機處理並先去識別化，不要上傳到雲端 AI。
- 這是來源保真與可稽核流程，不代表達到研究上的理論飽和。
